Welcome to the fifth installment! Explore immersive terrains due to Tectonic and Geophilic, and there is finally a quest book that you can follow to help you along the way to become powerful than ever before! Decorate your base with MrCrayfish's Furniture Mod that has been refurbished recently. Also find biomes with Nature's Compass and structures with the Structure Compass! This version will be taking it back to where it was before the previous installment with the amount of mods it has so that more people can play!
